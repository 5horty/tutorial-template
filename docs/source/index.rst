Project Documentation
=====================

Welcome to the Cook App project documentation.

This project is a full-stack recipe management application that allows users to
create accounts, browse recipes, add new recipes with images and step-by-step
instructions, and follow recipes with a guided cooking mode.

The project is split into two main parts:

- **Frontend** – A Flutter mobile application that provides the user interface
  and handles all user interactions.

- **Backend** – A Flask REST API that manages user accounts, recipe storage,
  search functionality, and step completion tracking.
